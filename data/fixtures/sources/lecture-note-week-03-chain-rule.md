# Week 03: Chain Rule

The chain rule is used when differentiating a composition of functions.

## Core rule

If y = f(g(x)), then:

y' = f'(g(x)) * g'(x)

## Compare with product rule

If y = u(x) * v(x), then:

y' = u'(x) * v(x) + u(x) * v'(x)

## Reminder

Use the chain rule for nested functions and the product rule for multiplication.
