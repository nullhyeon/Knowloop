# 3주차 강의노트: 연쇄법칙 (Chain Rule)

연쇄법칙은 함수 안에 다른 함수가 들어 있는 합성 구조(composition of functions)를 미분할 때 사용합니다.

## Core rule

If y = f(g(x)), then:

y' = f'(g(x)) * g'(x)

## Quick comparison with Product Rule

If y = u(x) * v(x), then use the product rule:

y' = u'(x) * v(x) + u(x) * v'(x)

## Teaching reminder

학생에게는 "식이 겹쳐 들어갔는지(nested)"부터 보게 하면 Chain Rule과 Product Rule을 더 빨리 구분할 수 있습니다.
